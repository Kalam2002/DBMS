Step 1:
sudo nano /usr/share/nmap/scripts/hello-nse.nse

Step 2:
Paste the following Code
-- hello-nse.nse
description = [[
Prints 'Hello NSE' on the Nmap output.
]]

author = "Your Name"
license = "Same as Nmap--See https://nmap.org/book/man-legal.html"
categories = {"discovery", "safe"}

-- This will run on any open port
portrule = function(host, port)
    return true
end

action = function(host, port)
    return "Hello NSE"
end

Press Ctrl + O to save.

Press Ctrl + X to exit nano.

Step 3:

sudo nmap --script-updatedb

Step 4:

nmap -p 80 --script=hello-nse.nse scanme.nmap.org
